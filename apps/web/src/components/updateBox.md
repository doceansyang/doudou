### 新增

- 文档工作区支持多标签、左右与上下分屏、快速打开和恢复已关闭标签，并记住打开的文档与布局。
- 文档页支持编辑纯文本文件、预览图片和音视频；PCM 音频可设置采样率、声道和采样格式后试听。
- 支持从文件树打开画布节点，在文档页继续查看和操作节点。
- 文件树支持新建文件与文件夹、复制、剪切、粘贴、重命名、拖动移动、批量删除和复制路径。
- 新增工作区全文搜索，可定位匹配内容，预览并批量替换勾选文件中的文本。
- 插件市场新增“文件扩展”，支持安装、启停、配置和导出，并可设置文件类型的默认打开方式。
- 文本节点支持 Markdown 预览、富文本与原文切换，以及 Markdown 文件下载。
- 图片与图片生成节点支持局部重绘，可涂抹修改区域并输入提示词，保留未涂抹部分。
- 图片支持宫格切分，可选择常用宫格或自定义行列数，切分后直接生成图片节点。
- 图片支持画笔、形状、文字和橡皮擦标记，以及撤销与重做；标记结果保存为新的图片节点。
- 新增音频生成节点，可根据文本或提示词生成音频，引用参考图片或音频，并设置语种、采样率和输出格式。
- 音频与音频生成节点支持波形剪辑、片段分割、粘合、删除和变速，处理结果生成新的音频节点（需安装 FFmpeg）。
- 视频与视频生成节点支持音轨提取、音视频分离和片段截取，可预览并调整截取范围，处理后保留原视频（需安装 FFmpeg）。

### 优化

- Markdown 文档支持原文与富文本切换、粘贴或拖入本地图片，并可打开工作区内的文件链接；大文档默认使用原文编辑。
- 文件树支持按文件或节点名称搜索，并按可见行渲染，改善文件和节点较多时的浏览体验。
- 复制画布时同步创建独立的节点、正文和节点自有素材副本，便于分别编辑。
- 画布选区工具栏增加水平、垂直和宫格排列入口，方便直接整理选中节点。
- 节点工具栏为添加到素材库、历史记录、替换素材等操作补充文字说明。
- 音频播放器增加波形、播放进度和音量控制，方便定位和试听素材。
- 视频节点顶部增加当前帧、首帧和尾帧截取入口。
- 扩展 Agent 音频生成参数，支持参考图片、音调和语种，并可操作音频生成节点。
- 文本文件支持 UTF-8 和带 BOM 的 UTF-16 编码，保存时保留原有编码。
- 完善文档工作区、文件扩展和媒体处理功能的多语言文案。

### 修复

- 修复文本文件被其他编辑器修改后仍直接覆盖的问题；保存冲突时保留当前编辑内容，并提供重新读取磁盘等处理入口。
- 修复取消音视频处理时任务尚未结束就清理文件的问题，改善取消操作和临时文件清理的可靠性。
- 修复部分插件配置中的嵌套字段无法正确保存、隐藏字段误触发必填校验的问题。
- 修复部分媒体生成结果因文件类型识别错误而无法保存的问题。
- 修复画布选区靠近边缘时工具栏按钮超出可视区域的问题。
